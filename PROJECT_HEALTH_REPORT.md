## 7. ⚠️ Найденные проблемы (некритические)

### Проблема 1: Несоответствие имени класса в engine.py

**Файл:** `src/modules/parsing/engine.py`  
**Суть:** Класс называется `ParserEngine`, но если его где-то импортируют как `ParsingEngine`, это вызовет ошибку.

**Рекомендация:** Унифицировать название класса. Либо переименовать класс в `ParsingEngine`, либо проверить все места импорта.

### Проблема 2: Отсутствует pytest

**Суть:** pytest указан в dev-зависимостях, но не установлен.  
**Рекомендация:** `pip install pytest pytest-asyncio` для запуска тестов из `tests/`

### Проблема 3: Предупреждение о шрифтах Qt

```
QFontDatabase: Cannot find font directory
```

**Влияние:** Косметическое, может влиять на отображение шрифтов в GUI.  
**Рекомендация:** Установить пакет шрифтов или настроить fontconfig.

### Проблема 4: playwrite browsers dry-run

Playwright установлен, но Firefox и WebKit могут быть не установлены Chromium установлен и используется в проекте.

## 9. Проверка экспорта изображений и склейки для входных дверей

### ✅ Склейка изображений реализована и интегрирована

**Реализация** (`src/modules/export/generator.py`):
- `_is_input_door()` (строка 509) — определяет входные двери по "входн" в title/category/attributes
- `_download_image_bytes()` (строка 516) — скачивает изображения через aiohttp
- `_merge_two_images_horizontally()` (строка 526) — объединяет два фото горизонтально через Pillow
- `_merge_door_images_async()` (строка 555) — асинхронная обработка всех товаров
- `_preprocess_images()` (строка 596) — синхронная обёртка
- `run()` (строка 650-655) — **автоматически вызывает** склейку когда находит входные двери

**Как работает:**
1. При запуске экспорта `ExportEngine.run()` проверяет все товары через `_is_input_door()`
2. Если найдены входные двери — вызывается `_preprocess_images()`
3. Первые два изображения каждой двери скачиваются и объединяются горизонтально
4. Результат сохраняется в `data/exports/merged_images/door_merged_*.jpg`
5. В CSV записывается путь к локальному файлу вместо URL

**Текущее ограничение:**
Для корректной работы нужны данные — товары в категории "Входные двери" с рабочими URL изображений.
Парсер tandoor.ru сейчас сохраняет товары в категорию "с зеркалом" (id=5) вместо "Входные двери" (id=2).
После исправления парсера и повторного парсинга склейка будет работать автоматически.

**Категории в БД:**
- id=2: "Входные двери" ✅ (должна применяться склейка)
- id=5: "с зеркалом"
- id=22: "Межкомнатные двери" ✅ (склейка НЕ применяется — корректно)
